# Intake Question Bank

Use these when the profile isn't already evident from context. Skip anything already answered. If the user says "just use defaults" or similar, use the defaults noted below and flag clearly which fields were assumed rather than stated.

## 1. Core profile
- Current role / field / job title
- Years of experience, seniority level
- Key skills / tech stack / certifications
- Highest education level + field
- Current city/country of residence
- Nationality / passport(s) held (critical for visa feasibility — a search can't tell you this)
- Default if skipped: assume no special visa constraints, flag this assumption loudly.

## 2. Location
- Willing to relocate? (yes / remote-only / no)
- Specific target countries or cities, if any — or "open to anywhere with sponsorship"
- Any locations to explicitly exclude
- Work mode acceptable: remote / hybrid / on-site / any
- Default: remote-first, open to relocation for a strong enough offer.

## 3. Compensation
- Minimum acceptable salary (floor — hard filter)
- Target/ideal salary
- Currency
- Gross or net?
- Compare raw salary or cost-of-living/purchasing-power-adjusted?
- Default: compare cost-of-living-adjusted, since that's what actually matters for "most money for it" across countries.

## 4. Priorities (advantages) — ask user to rank or pick top 3
- Visa sponsorship availability
- Remote flexibility
- Salary / total comp
- Benefits (health, PTO, parental leave)
- Career growth / title progression
- Job security / company stability
- Work-life balance
- Local tax burden (net take-home)
- Relocation package / support

## 5. Deal-breakers
- Anything that disqualifies a role outright (no sponsorship, on-site only, below salary floor, disliked industries, company size, etc.)

## 6. Timeline / intent
- Actively applying now vs. exploring options
- How many opportunities they want in the shortlist (default: 5–8, quality over quantity)

## Fast-path default persona (only if user explicitly wants to skip intake)
Generic profile: remote-friendly, no visa constraints assumed (flagged), ranks by cost-of-living-adjusted salary (40%), remote flexibility (25%), career growth (20%), benefits (15%), shortlist of 6. State explicitly that this is a placeholder and the user should correct any wrong assumption before you spend search budget on it.
